### 1. إصلاح كتابة النص (text-output.js)
- **المشكلة**: كان يستخدم PowerShell SendKeys + Ctrl+V للصق → كان يكتب حرف "v" بدل اللصق، وترتيب النص العربي RTL معكوس
- **الحل**: استبدال بـ Windows API `SendInput` مع `KEYEVENTF_UNICODE` — يكتب كل حرف مباشرة عبر PowerShell persistent + C# KeySender
- **ملاحظة**: إرسال كل الأحرف دفعة واحدة يسبب تكرار أحرف (struct alignment issue)، الحل: إرسال حرف بحرف مع `Thread.Sleep(5)` بينها
- **ملاحظة**: النص العربي يُمرر كـ Base64 (UTF-16LE) لتجنب مشاكل ترميز PowerShell

### 2. إصلاح معالجة tokens من Soniox (soniox-client.js)
- **المشكلة**: كان يكتب فقط عند is_final=true → تأخير كبير. وأحياناً يفوّت كلمات عند تصحيح Soniox للنص
- **الحل**: كتابة non-final tokens فوراً + throttling 120ms + تتبع typedText لكتابة الجديد فقط
- **المشكلة**: عند تصحيح Soniox (currentFullText لا يبدأ بـ typedText)، كان يُعيد كتابة النص كاملاً → تكرار
- **الحل**: عند التصحيح والنص أطول → كتابة الحروف الإضافية فقط. عند نفس الطول أو أقصر → تحديث التتبع بدون كتابة
- تصفية `<end>` tokens والنقاط التلقائية قبل `<end>`. تغيير `max_endpoint_delay_ms` من 500→3000
